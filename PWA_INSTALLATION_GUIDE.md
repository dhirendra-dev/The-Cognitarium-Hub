# Board Exam Preparation - PWA Installation Guide

Your **Board Exam Preparation** app is now available as a Progressive Web App (PWA) that can be installed on Android, iOS, and desktop devices like a native app!

## What is a PWA?

A Progressive Web App (PWA) is a web application that works like a native app:
- ✅ **Installable** - Add to your home screen
- ✅ **Offline Support** - Works without internet
- ✅ **Fast** - Loads quickly even on slow networks
- ✅ **Push Notifications** - Get study reminders
- ✅ **Full Screen** - No browser address bar
- ✅ **Easy Updates** - Always get the latest version

## Installation on Android

### Method 1: Using Chrome Browser (Recommended)

1. **Open the app in Chrome**
   - Go to: https://hslcprep-fefyutzm.manus.space
   - Wait for the page to fully load

2. **Install the app**
   - Look for the **"Install"** button in the address bar (or menu)
   - Tap the install icon (looks like a download arrow or house icon)
   - Confirm the installation

3. **Access the app**
   - The app will appear on your home screen
   - Tap the "Board Exam Preparation" icon to launch
   - It will open in full-screen mode without the browser UI

### Method 2: Using the Menu

1. Open the app in Chrome: https://hslcprep-fefyutzm.manus.space
2. Tap the **three-dot menu** (⋮) in the top-right corner
3. Select **"Install app"** or **"Add to Home screen"**
4. Confirm the installation

---

## Installation on iPhone/iPad

1. **Open in Safari**
   - Go to: https://hslcprep-fefyutzm.manus.space

2. **Add to Home Screen**
   - Tap the **Share** button (arrow pointing up from a box)
   - Select **"Add to Home Screen"**
   - Enter a name (or use default "Board Exam Prep")
   - Tap **"Add"**

3. **Access the app**
   - The app icon will appear on your home screen
   - Tap it to launch the app in full-screen mode

## Installation on Desktop/Laptop

### Windows/Mac (Chrome/Edge)

1. **Open the app**

## Troubleshooting

### "Install button not showing"
- Make sure you're using Chrome, Edge, or Safari
- Refresh the page (Ctrl+R or Cmd+R)
- Wait 2-3 seconds for the app to load completely
- Try a different browser if it still doesn't work

### "App not opening"
- Check your internet connection
- Clear the app cache: Settings → Apps → Board Exam Prep → Storage → Clear Cache
- Uninstall and reinstall the app

### "Offline features not working"
- The app caches content as you browse
- Some features require internet (like syncing progress)
- Core study materials will be available offline after first load

### "Updates not showing"
- The app auto-updates in the background
- Force refresh: Swipe down on the app or press Ctrl+Shift+R
- Uninstall and reinstall for major updates
