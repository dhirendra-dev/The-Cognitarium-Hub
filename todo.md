## Technology Stack

- Frontend: React 19, Tailwind CSS 4, TypeScript
- Backend: Express 4, tRPC 11, Node.js
- Database: MySQL with Drizzle ORM
- Storage: S3 for PDF files
- AI: Manus Forge LLM integration
- Authentication: Manus OAuth
